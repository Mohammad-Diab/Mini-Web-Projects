Mini Web Projects

Small web projects by Mohammad Diab, each in its own folder.

  • Toggle Button2018

    A toggle switch: click it and the knob slides across while the background fades between light grey and green.
  • CSS Tooltip2018

    A tooltip made with CSS only, fading in above the text on hover.
  • My Logo2018

    An animated logo page: the picture grows inside spinning rings above "Hi, I'm Mohammad."
  • Four Plus2018

    The web version of the Four Plus number-guessing game in a console-style window.
  • Calculator2018

    A simple calculator with digits, brackets and the four basic operations.
  • Dynamic Table2018

    A table whose rows and cells are built by JavaScript.
  • Login2018

    A login form whose icons come from one CSS sprite image.
  • SVG Progress Ring2019

    A small JavaScript library that draws an SVG progress ring with a start angle, percentage, colour and direction.
  • Fluent Design2019

    Six UI controls styled after Microsoft's Fluent Design: buttons, checkboxes, links, progress bars, radio buttons and toggle switches.
  • TimeLine2019–2021

    A timeline of projects and technologies over years and months, drawn by a small JavaScript class from data.json, a page at a time.
  • Sprite Icons2020

    Three SVG icons drawn as a sprite of symbols, with live stroke and fill colours.
